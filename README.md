<p align="center">Sof HTML, CSS va JavaScript'da yozilgan onlayn do'kon sahifasi.</p>

## ✨ Imkoniyatlar

- 🧾 Mahsulotlar katalogi (`products.js` dagi ro'yxatdan dinamik chiqariladi)
- 🏷️ Kategoriyalar bo'yicha filtr: Elektronika, Kiyim, Uy jihozlari
- 🛒 Savat: mahsulot qo'shish, o'chirish, umumiy summani hisoblash
- 💾 Savat `localStorage` da saqlanadi
- ✅ Buyurtma berish

## 📁 Tuzilma

```
├── index.html    # Sahifa tuzilishi
├── style.css     # Uslublar
├── products.js   # Mahsulotlar ma'lumotlari
└── script.js     # Savat va filtr mantig'i
```

## 🚀 Ishga tushirish

Hech qanday o'rnatish kerak emas:

```bash
git clone https://github.com/Zikrillayev77/Online-dokon.git
cd Online-dokon
```

So'ng `index.html` faylini brauzerda oching (yoki VS Code'dagi **Live Server** kengaytmasi orqali).
